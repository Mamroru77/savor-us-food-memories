# Savor · 本轮 UI 优化

日期：2026-09-16

## 已落地

- **P0｜身份提示与主题**：云端工具、年度报告的身份提示改为只在锁定时显示，不再位于正常正文上方。账号、双人空间、云端工具、年度报告统一接入 Pearl / Nocturne 二级页面样式；身份提示组件补充设备主题适配。
- **P1｜控件与入口**：统一二级页面卡片、主次/危险操作、输入框、焦点、点击反馈、状态与空列表提示；整理“我们”的空间管理入口、帮助页的云端反馈入口及 Add 已有导入入口样式。年度报告页面和分享确认提示补充中英切换，分享默认范围和确认保护不变。
- **P2｜实拍细修**：模拟器加载态截图显示禁用按钮文字过浅，已补充明确文字颜色及适当透明度。未对缺乏实拍依据的日期尺寸、Memory Row 分隔线或 Add 省略号作猜测性修改。
