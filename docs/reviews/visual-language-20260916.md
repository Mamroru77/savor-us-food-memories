# Savor｜概念母版驱动的五轮视觉迭代

2026-09-16 · 已修改实际微信小程序 · 不是只制作展示图

## 执行原则

图一作为核心视觉母版，图二作为基线。本次先完成逐页 Gap Analysis，再连续进行五轮“修改 → 原生运行 → 截图 → 对照 → 微调”。保留中文内容、页面结构、真实资料和全部功能，没有用示例照片或减少菜单来制造接近概念图的假象。

**本次结果：**既有 8 个应用 WXSS 文件调整，新增 1 个视觉 Token 文件；其余 180 个既有应用文件未改。应用 JS、WXML、字体载荷均未改。五轮最终完整回归均通过。

这是当前中文亮色状态的阶段性视觉收敛记录，不是全主题、全交互或真机最终验收声明。

## 1. 从差距到实际调整

完整修改前分析见 `reports/visual-language-20260916/gap-analysis.md`。

### Round 1｜全局材质、标题与二级页

- 新增 `miniprogram/styles/visual-tokens.wxss`，通过现有 `app.wxss` 导入。
- 基础底色改为安静暖灰白，移除原基础背景叠加的四层渐变。
- 照片氛围层透明度由 0.22 调低为 0.12，没有增加模糊半径。
- 共用内容卡片减少透色，使用单一轻阴影，降低照片色块对正文、字段和菜单的干扰。
- 中文普通页面标题由 46rpx 接入 48rpx 的共同层级；不是统一放大所有文字。Home 既有双行 Hero 保留。
- Account / Space / Workspace / Reports 同步接入页面边距、卡片内距与圆角。

**截图判断：保留。** 五个主页面的背景更安静，内容与背景分离更清楚；四个业务二级页也检查了真实页面，不只调整首页。

### Round 2｜Home / Us 卡片比例

- Home Weekly 高度 352 → 320rpx；保留 215rpx 的照片，不靠缩小图片换空间。
- Home / Us 接入共同页面边距与卡片圆角。
- Us 关系卡 332 → 352rpx，统计卡 355 → 300rpx；降低第二层统计的视觉重量。
- Us 共享图库提前出现；保留双人空间管理入口，不改信息架构。

**截图判断：保留比例调整。** Home 的近期内容更早出现；Us 的共享照片获得更多首屏可见空间。但后续对照发现周统计数字间距略紧，已在 Round 5 修正。

### Round 3｜Add 空状态与 Me 列表

- Add 主封面占位使用清楚但克制的浅色表面，补充照片入口使用更轻的边界，形成主次。
- 主封面改为可伸缩宽度，保留高度与 `aspectFill` 图片模式。
- 弱化输入框边界和标签字重，校准字段组间距；保留错误/焦点反馈与 88rpx 级点击区域。
- Me 统计卡 260 → 280rpx、图表高度 60 → 80rpx，给个人旅程更多空间。
- Me 菜单由固定 124rpx 行高改为最小 136rpx、允许随内容增长；不删除入口或压缩长文案。

**截图判断：保留。** Add 的空封面不再与背景混在一起，Me 的下半部分不再依赖固定矮行压缩信息。空草稿仍然是空草稿，没有填入概念图照片。

### Round 4｜共用列表与 Sheet 外壳

先取得 Profile / Library / Preferences / Help 的原生基线，再调整、重拍。

- Memory Row 缩略图 110×115 → 112×128rpx，改为稍竖向比例；行高和上下内距一起匹配。
- 列表标题与辅助信息层级更清楚。原分割线策略未改，未绕过尚未复现的分割线问题。
- Sheet 接入大面板圆角和悬浮阴影 Token；普通面板标题与页面标题层级靠拢。
- 面板表面不透明后，去掉面板自身原有的 62rpx backdrop blur；保留遮罩分离效果、退出动画和 Quiet。
- 未改变面板高度计算、滚动、关闭、原生选择器或未保存字段守卫。

**截图判断：保留。** 四个面板与主页面的边界和材质更一致，Library 图片更突出。没有通过新增动画或玻璃层制造差异。

### Round 5｜回看后的局部微调

再次对照概念图与 Round 4，发现 Home 两组周统计数字有些靠近。只调整这组水平留白，让数字之间重新有呼吸空间，没有继续放大整张卡片。

**截图判断：保留。** 这是对上一轮判断的修正，不把“已经改过”当作定稿理由。最后重新截图全部五个 Tab 并生成新预览。

## 2. Design Token 的范围

目前已形成：

- 暖灰白页面、内容卡片、浮层三个语义表面。
- 页面边距、卡片内距和 12 / 24 / 32 / 40 / 56rpx 的间距级别。
- 控件、图片、卡片、大面板的圆角角色。
- 页面标题、中文标题、章节、正文、辅助信息和次级统计的文字角色。
- flat / card / floating 三个阴影角色。
- 140 / 220 / 320ms 的动效规范入口。

这是**逐步接入**，不是已经消除了所有 magic number。圆形头像、胶囊按钮、地图悬浮控件有不同职责，不强行套成同一种圆角；Nocturne 的既有颜色与未验证的特殊阴影保持谨慎。

没有引入新的 UI 库、字体包、运行时样式引擎或设计系统框架。

## 3. 导航与动效为什么没有强改

已经核对五个 Tab 的共用样式：统一标签、active/inactive 颜色、中央 130rpx 按钮、150ms 按压反馈及 Quiet。

- 静态比例已有明确的主次，没有足够依据为了“本轮必须改导航”而缩小安全区或点击区域。
- 中央 Add 保留餐具图标，不改回概念图的加号。
- Tab 的 JS / WXML / WXSS 均未改，没有重新应用已被否决的优化。
- Map 自身的 JS / WXML / WXSS 均未改，只随共用卡片材质发生视觉变化；坐标、Marker、拖拽、堆叠和点击行为保留。
- 既有约 150ms 按压、220ms Toast、320ms Sheet 已符合克制反馈方向，不为统一变量写法而新增动画。
- **真机 Tab 抽动仍未解决，也没有拿截图或测试次数证明流畅。**
