## 9. Responsive

Supported width verified: **428 pt** (the only width the DevTools simulator exposes; the tooling has no
viewport-resize action). Both changes are rpx-based, so content width is width-invariant:

* `.recent-title` now inherits `--space-md`, the same token the list padding uses ⇒ the rail holds at
  every width by construction.
* `.locale-zh .home-intro-sub` needs 17 × 27 rpx = **459 rpx**; available content width is
  `750 − 2×40 (gutter) − 2×30 (intro padding)` = **610 rpx**, so the one-line result holds on any
  supported phone. Narrower hypothetical widths were not redesigned for.
