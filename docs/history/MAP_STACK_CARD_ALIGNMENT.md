# Map 堆叠与底部卡片一致性调整

日期：2026-09-13  
基线：1802d97  
用户选择：保留照片地标、真实位置与向上展开方向，只统一展开/收起动效和按钮。

> **本包修复范围是地图。Tab 真机图案回跳仍未闭环，Tab 运行时文件保持原样，不宣称本包修复了 Tab。** 用户确认属于图案回跳，原始 MP4 尚未收到。

## 地图已实施

### 1. 与底部卡片相同的 320ms 整体缓动

- 统一为 320ms，曲线对应底部卡片 `cubic-bezier(1/3, 0, 2/3, 1)`。
- 其横轴 x=t，纵轴为 `t*t*(3-2*t)`；驱动层只应用一次缓动。
- 移除各张卡片的额外错峰和二次缓动。整组照片位置、透明度与翻页空间共享进度。
- 保留 80×89px 地标、101px 完全展开间距、原根地标底部锚点和向上展开方向。
- 快速反向从当前可见进度开始；Quiet 立即完成；退出清理定时器。

### 2. 修复最后一页收起时跳回第一页

旧逻辑每次切换展开/收起都把 drawerPage 设为0。最后一页不足三张时，收起瞬间会换成第一页三张，导致内容和高度突变。

现在：收起及中途反向保留当前页及其记录；完全关闭后重新开启仍从第一页开始。没有更改分页容量或记录顺序。

### 3. 按钮对齐底部卡片

- 复用同一官方 Lucide chevron-up/down，1.75 描边，没有替换为新图标家族。
- 手机基准：56rpx 可见圆角材料、24rpx 圆角、28rpx 箭头；浅色与暗色采用底部按钮相同配色。
- 原生地图采用96×96 PNG导出，同样保留透明背景。原生 cover-image 不支持底部玻璃卡片的实时背景模糊，因此实现同规格/配色，不声称两种渲染层像素完全一致。
- 图形中心仍为原生堆叠坐标 (44px,16px)，不会改变地标位置。
- 横向命中宽度至少44px；纵向扩大为40px，范围为 -4..36px，正好止于翻页栏起点，不覆盖相邻操作。
- 手机375/390/430宽度下图形与底部按钮按相同rpx比例换算；更宽窗口在430手机尺度封顶，避免固定原生堆叠中的按钮压到翻页栏。不是桌面布局重构。
- 按压时原生图形以0.85透明度反馈，匹配底部按钮；松手、取消、地图手势和页面隐藏均清理按压状态。

### 4. 翻页栏不再在收起开始时消失

翻页栏在展开/收起期间保持挂载，按同一进度收缩高度及淡出，结束时才移除。未完整展开或正在收起时不接收翻页点击。

栏底端为 `36 + 30p`，第一张照片上沿为 `40 + round(28p)`；0≤p≤1时不重叠。图片和原生可见图层不会因地图拖动而被隐藏。
