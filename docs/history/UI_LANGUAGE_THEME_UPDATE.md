# 地图卡片、待定位气泡、语言和暗色模式更新

## 本轮完成范围

### 1. 餐馆卡片更透明

- 浅色卡片底色不透明度由 `0.83` 降为 `0.62`，保留玻璃模糊。
- 次级文字使用更深的颜色，避免透明背景降低可读性。
- 修复截图中“校准位置 / 在腾讯地图打开”落在卡片外的问题：操作区收进卡片底部。
- 卡片只显示完整位置地址，不再在后面冗余拼接可能过时的城市/国家。这是显示调整，**没有修复数据库内地理元数据**，详见业务核查。

### 2. 待定位提示收纳为气泡

- 默认收起为带图钉和数字的气泡，位于右侧导航/回中键下方。
- 点击展开：显示待定位数量、说明和“选择记录并补充”。
- 再点气泡或展开面板的 × 可以收起。
- 开始选择记录时自动收起，原补定位业务不变；没有新增云请求或重做地图。
- 位置通过原 overlayTop 与 rpx 间距计算，跟随屏幕尺寸，不使用截图的物理像素硬定位。

### 3. 应用内语言设置

入口：**我的 → 设置 → 应用语言**（English: Me → Settings → App language）。

选项：
- 跟随系统 / Follow system
- 简体中文
- English

语言存于原 `savor-diary-v1` 的 `settings.language`，重启后保留。旧缓存没有语言字段时默认跟随系统；中文系统语言映射为简体中文，其他语言回退 English。这里的“跟随系统”使用微信提供的语言信息。

覆盖：TabBar、五个页面、Sheet 二级菜单、帮助/隐私说明、表单提示、业务错误、显示日期和应用控制的弹窗。

不会修改：手机/微信系统语言、餐厅名、用户笔记、地址、个人简介、已保存标签、CloudBase schema。系统原生选图/地图弹窗的语言由微信/系统控制。

实现：
- `utils/i18n.js`：语言解析、文案、日期上下文和页面标签推送。
- `utils/locales.js`：336 条双语 UI 文案，使用 `tools/lib/locale-translations.tsv` 维护。
- 修改文案后运行 `npm run build:locales` 生成确定性的字典。
- 固定饮食/菜系设置以翻译后的 label 展示，但保存原 value，避免切换语言改变筛选与数据语义。
- TabBar **依然零 require / 零 store 依赖**。页面只推送 labels/theme，语言同步不会改 selected，避免后台页面订阅抢走当前 Tab 高亮。
- 同步纠正了隐私页旧文案“无云同步、只在本机”的错误描述。现在明确区分云餐食与本地 UI 状态。

### 4. 暗色模式

- 页面改为更深的炭灰/森林绿，不再只是把浅色界面染成灰绿色。
- 统一正文、次级文字、输入框、面板、选中态、错误提示与按钮的暗色对比度。
- SVG 图标显式传入暗色前景色，不依赖它们无法继承的 CSS color。
- TabBar 与中央 Add 按钮一起变暗，避免底部残留亮白按钮。
- 动态背景照片仍保留，但降低暗色时的亮度/饱和度，照片主体不反色。
- 地图使用不拦截触摸的轻量减亮遮罩，卡片/筛选/气泡独立适配暗色；**没有声称接入腾讯服务端的夜间地图瓦片样式**。
- 保留 Quiet motion 和原页面结构。

## 验证

`npm run verify:all`：
- 原主静态验证 **187/187 PASS**。
- 原 TabBar / 资产独立验证 PASS。
- mock 契约场景 **47/47 PASS**。
- 新增检查覆盖气泡展开/收起、卡片内容高度、双语 key 完整性、语言立即切换/重启/跟随系统、用户数据不被翻译、TabBar 不抢选中态、Settings 语言入口，以及选定色对的 WCAG 对比度。
- 静态 store 沙箱增加对真实 i18n/locales 模块的严格白名单加载；没有删除测试或用空实现跳过新依赖。
- 原 UI 基线不删除；用户本轮要求改变的文件以附有原因的哈希清单记录。原 TabBar 零业务依赖验证继续执行。

**未在微信开发者工具、真机或真实 CloudBase 执行本轮验收。** 色值计算和结构测试不能替代真实地图上的视觉检查。

## 本轮部署与人工检查

本轮没有修改 `cloudfunctions/`，若已部署上一版 mealRecords，只需更新前端工程并重新编译，不需要重新部署云函数。

建议真机检查：
1. Map 查看卡片透明度、底部操作区是否仍在卡片内。
2. 点导航键下方数字气泡 → 展开 → × 收起 → 选择待定位记录。
3. 我的 → 设置 → 简体中文 / English，检查 TabBar、Add、Sheet 的立即切换；重启确认保留。
4. 切换跟随系统，重新进入小程序；验证应用读取微信提供的语言。
5. 切换暗色，检查地图、Sheet 长列表、输入框、图标和底部 TabBar。
