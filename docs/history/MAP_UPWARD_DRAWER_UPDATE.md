## Console 报错含义与修复

截图中的 `moveToMapLocation:fail 开发者工具暂时不支持此 API 调试，请使用真机进行开发` 来自地图移动 API 的模拟器支持限制，不代表餐厅坐标错误、照片丢失或云函数失败。

代码原先直接调用 MapContext.moveToLocation，没有失败处理。本轮：
- 检测 platform=devtools 后不调用该 API。
- 使用绑定中心坐标与只含当前餐厅真实坐标的 includePoints 回退，解决手动拖动后再次定位的问题；不会为了选中一家餐厅而把所有餐厅一起缩放。
- 真机仍保留 moveToLocation，并处理 fail 回调和同步异常；失败后使用回退，避免反复调用不可用方法。
- 迟到的失败回调不能把新选择拉回旧餐厅。概览视图单独处理，仍允许包含所有可见餐厅。
- includePoints 回退可能采用不同缩放级别；视觉效果需原生环境核对，不宣称与真机移动动画完全相同。

## 附近餐厅向上抽屉

- 沿用按屏幕缩放距离分组的逻辑，第一家作为地图真实位置上的主标记。
- 在主标记下方显示小箭头及组内数量；箭头展开／收起。点击多餐厅主标记也可展开。
- 其他餐厅以照片快印标记组成垂直向上的列表，第一项邻近主标记，其余向上延伸。使用原生 map 的 customCallout 与 cover-view/cover-image，不为视觉排布伪造经纬度。
- 点击子项后底部详情卡更新，抽屉保持展开，主标记仍为本组原来的第一家；可点击主标记位置重新选择第一家。
- 每页最多显示 3 个子项，更多项目通过顶部左右箭头翻页，避免抽屉无限增高；同坐标 9 条记录均可访问。
- 原独立餐厅选择列表移除，底部卡片不再因抽屉打开而隐藏；340rpx 卡片、方图、内部收起按钮、Map D 不重复店名的要求保持。餐厅名字仍在底部卡片／收起条，抽屉只显示照片标记和数量。
- 搜索／过滤／缩放使组拆开时关闭抽屉。页面退出后清理渲染器；迟到的照片结果不能写入新抽屉。
- 复用现有私有照片快印渲染与本地兜底，不新增商家抓图、云函数调用、食记写入或公共图片权限。

## 更新方式

仅客户端更新：使用最新版项目正常编译／发布即可。无需部署云函数、不改腾讯 Key、不清缓存、不重传照片。

建议验收：
1. 进入 Map，选择餐厅并拖动后重新选择，不再触发截图中的模拟器移动 API 错误。
2. 两家附近餐厅：箭头在首家下方；展开后第二家在上方，点击切换底卡，首家锚点不被替换。
3. 4 家及以上：分页可达所有项目；抽屉不能截断到不可操作；检查小屏顶部页头附近的遮挡情况。
4. 收起／缩放拆组／筛选／退出重进后无旧照片或残留抽屉；底卡仍可操作。
5. 真机确认地图调用回退、照片加载、触摸和锚点偏移。若有错位，提供展开与收起各一张截图，不改变真实餐厅坐标来“修”视觉位置。
