# 二级菜单滚动与常规黑色模式

## 本轮修复

此前 Sheet 的 `86vh` 滚动区估算与实际标题、面板内边距不完全一致，而且面板底部位于自定义 TabBar 后方。即使内容滚到最后，底部按钮仍可能被底栏遮挡。

- 所有二级 Sheet 共用修复：面板底部预留 170rpx 底栏 + 24rpx 间隙 + 系统安全区，顶部避开胶囊。
- 移除 `86vh` 和 550rpx 最小高度，面板由上下边界明确约束。
- 布局完成后测量面板与标题实际边界，计算滚动视口高度，扣除底部内边距；测量不可用时使用受约束的 flex 回退。
- 滚动内容末尾添加 72rpx 留白，便于最后一项/保存按钮完整进入可见区域。
- 窗口尺寸变化重新测量；组件销毁解除监听，忽略迟到回调。保留 scrim 手势拦截，不在面板上拦截滚动。

暗色主题改为**中性黑灰**：页面 #101010，内容卡片 rgba(24,24,24,.76)，弹层 rgba(22,22,22,.98)，底栏和按钮使用灰阶，文字/图标为白灰色。暗色下关闭环境背景照片层，避免残留绿色光晕；餐食照片、头像和地图本身不去色。错误提示仍保留语义颜色。亮色布局和样式保持原有方案。内部主题值仍为 `dusk`，原用户设置无须迁移。
