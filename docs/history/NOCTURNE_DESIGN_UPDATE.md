# Nocturne：检索参考后的暗色重设计

## 检索与参考（2026-09-11）

本轮进行公开网页检索，并阅读官方设计说明、材质规范及候选网站；不是声称遍历全网，也不把搜索摘要当作已验证的设计规范。

1. [Linear 官方改版说明](https://linear.app/now/how-we-redesigned-the-linear-ui)：减少视觉噪声、维护对齐和导航层次，且将视觉改版与复杂导航重构分开。参考其克制的层级组织，而非复制产品布局。
2. [Vercel Geist · Colors](https://vercel.com/geist/colors)：背景、组件背景、边框和文字分别承担不同角色。借鉴语义分层，不把所有元素统一改灰。
3. [Vercel Geist · Materials](https://vercel.com/geist/materials)：区分页内表面与浮层，用尽可能低但清晰的高度层级，暗色下不能只依赖阴影。借鉴细边缘光与明确的表面差异。
4. [Raycast 官网](https://www.raycast.com/)：作为候选网站检索和浏览；不直接采用其品牌资产或配色。本轮核心落地依据是前述 Linear / Geist 原则。
5. Linear 网站图例来自 [LogRocket 的 Linear design 文章](https://blog.logrocket.com/ux-design/linear-design/)，已查看公开图例。参考图单独归档在源码仓库 `design-references/`，未嵌入小程序。

## 为什么重新做

上一版虽去掉了绿色，但背景、卡片、按钮都趋于相似灰度；全关环境光让原本的玻璃材质变成平面。新方案保留黑色基调和 Savor 的照片、衬线数字/英文、中文标题及布局，不照搬技术网站的霓虹光效。

## 本轮设计落地

| 层级 | 新方案 |
|---|---|
| 画布 | #121315 炭黑，顶部非常轻的中性光照 |
| 环境图 | 5.5% 不透明度、灰度模糊；只补充深浅，不恢复绿色光晕 |
| 内容卡片 | rgba(43,44,47,.90) → rgba(28,29,32,.90)，统一细边框、边缘光和 20px 模糊 |
| Sheet | #303135 → #25262a，比页内卡片略亮 |
| 输入框 | #1c1d20，向下凹入，而不是与浮层糊在一起 |
| 主文字 / 次文字 | #eeeae3 / #b6b2aa，柔和米白与暖灰 |
| 强调 | #dec8a7 香槟色，仅用于选中导航、开关、恢复默认等操作提示 |
| 中央 Add | 明亮但低饱和的香槟色表面 + 深色加号，重新建立主要入口 |
| 其他主按钮 | 深铜灰渐变 + 浅色文字，不让一整片浅色按钮抢走照片 |

Home / Map / Us / Me 八处内容卡片仍统一材质。Me 菜单增加暗色可辨的轻分隔线。暗色文字和图标同时更新；错误提示保留语义颜色。头像及餐食原图不去色。

## 验证

189/189 静态检查、62/62 mock 场景通过。保留滚动测量、底栏避让、保存草稿/失败回滚、语言、CloudBase 主链路等测试。旧灰阶断言更新为本轮实际色值和材质断言；修正卡片检查中把 `profile-menu-row` 误认为 `profile-menu` 的字符串前缀误匹配。

按实际色值端点计算：主文字/卡片 11.64:1，副文字/弹层 6.15:1，主按钮文字 7.22:1，中央 Add 加号 7.13:1，强调文字/浮层 8.58:1。透明材质在不同背景上的实际合成仍需设备检查。

**未执行微信开发者工具、真机或线上 CloudBase 验证。** 未变更 Sheet 滚动逻辑、页面尺寸、个性化功能或业务统计，也未更换字体。亮色主题保留；没有新增云函数、依赖库或后端配置。

建议原设备重点复核四页卡片、暗色 Map 上的地点卡、Sheet 输入/保存按钮、中央 Add 与选中导航，确认不出现绿色光晕或浅色图标落在浅色按钮上的情况。
