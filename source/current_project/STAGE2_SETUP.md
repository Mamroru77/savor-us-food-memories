# 阶段 2：记一顿 → 云数据库 → 首页自动更新

本阶段已新增：

- `miniprogram/pages/add/`：新增一顿饭的表单页面
- `cloudfunctions/mealRecords/`：记录的新增与读取云函数
- 首页 `onShow` 自动读取最新记录与统计
- 照片自动上传云存储，首页显示最近照片
- `dining_records` 集合由云函数首次调用时自动创建

## 首次运行只需要做 2 步

1. 微信开发者工具中，右键 `cloudfunctions/mealRecords` → **上传并部署：云端安装依赖**。
2. 点击 **编译**。首页点中间 `＋` 或「记下第一顿」，填写后保存。

保存成功返回首页时，首页会自动刷新。

## 当前数据隔离

本阶段云函数只读取当前微信 OpenID 自己创建的记录。下一阶段做「情侣绑定」时，再把 `memberOpenids` / `coupleId` 接起来，使两个人看到并共同编辑同一份记录。
