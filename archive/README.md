# 历史交接归档

[返回项目首页](../README.md)

`legacy-handoff/` 保存原分支中早于当前可运行项目的资料：旧源码、压缩包、设计图、问题视频、交接说明和提示词文件。它们仅供追溯，文件内容及提交历史保留，不代表当前实现或现行操作指令。

- 当前运行入口：根目录 `project.config.json`。
- 旧入口：`legacy-handoff/source/current_project/`，**不要作为当前项目部署**。
- 早期图片位于 `legacy-handoff/references/`，视频为该目录根层的 `vbug*.mp4`。
- 本轮仅归类已经存在于远端的资料，不执行历史内容清洗，也不重新发布本机私有运行证据。
- 当前工作机使用部分克隆，旧资料仍以 Git 对象和索引记录保留，未全部下载到磁盘；普通完整克隆可获得它们。仅本机目录为空不表示 Git 中的归档丢失。
